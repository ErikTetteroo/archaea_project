README - Cluster scripts for archaeal codon/tRNA analysis

This folder contains the Bash and Python scripts used on the cluster to prepare the genome, codon-usage, codon-pair, tRNA, and taxonomy data used in the R analyses.

The scripts were used as a small data-preparation pipeline. They are described below in the order they were used.

-----------------------------------------------------------------------------------------------------------------

1. INPUT: accessions.txt

The starting point is an accessions.txt file containing the NCBI genome accession numbers, one accession per line.

-----------------------------------------------------------------------------------------------------------------

2. Download genomes - Download genomes.sh

Purpose:
Download the genomes from NCBI using the NCBI datasets command-line program.

Input:
- accessions.txt

Output:
- One ZIP file per accession in /scratch/.../genomes/
- The downloaded datasets contain CDS sequences because the script uses --include cds.

Run from the folder containing accessions.txt.

After downloading, the ZIP files were unpacked with:

    for file in *.zip; do unzip -o "$file"; done

The CDS files were then collected into one folder and renamed using the accession:

    mkdir -p /scratch/.../genomes/cds_files

    for dir in /scratch/.../genomes/ncbi_dataset/data/*; do
        acc=$(basename "$dir")
        cp "$dir"/*cds_from_genomic.fna /scratch/.../genomes/cds_files/${acc}.fna 2>/dev/null
    done

The exact scratch path on the cluster depends on the user.

-----------------------------------------------------------------------------------------------------------------

3. Calculate codon usage and GC3 - genome_cutot.py

Purpose:
Calculate genome-wide codon counts, RSCU values, and synonymous GC3 (GC3s) from a CDS FASTA file.

Input:
- One CDS FASTA file (.fna)

Output:
- One .blk file in the directory codon_analysis_results_genomewise/

The output contains:
- Codon counts
- RSCU for each codon
- Genome-wide synonymous GC3
- Total number of codons

Example:

    python genome_cutot.py <cds_fasta>

-----------------------------------------------------------------------------------------------------------------

4. Calculate codon usage, GC3 and RDCU - genome_cutot_RDCU.py

Purpose:
Calculate the same codon-usage information as genome_cutot.py, plus codon-pair counts and relative dicodon usage (RDCU).

Input:
- One CDS FASTA file (.fna)

Output:
- One .blk file in codon_analysis_results_genomewise/
- One *_RDCU.csv file containing codon-pair information

The RDCU file contains:
- Codon pair
- The two constituent codons
- RDCU
- Observed codon-pair count
- Initial expected codon-pair count
- Constituent amino acids
- Observed and expected amino-acid-pair counts

The script uses the Biopython SeqIO parser.

Example:

    python genome_cutot_RDCU.py <cds_fasta>

In the original analysis, the script was run over all CDS files with a loop similar to:

    for file in /scratch/.../genomes/cds_files/*.fna; do
        echo "Processing $file"
        python scripts/genome_cutot_RDCU.py "$file"
    done

The two scripts are alternative codon-analysis scripts. genome_cutot_RDCU.py was used when both codon-level and codon-pair data were needed.

Before running the Python scripts, a Python environment with Biopython was loaded. The original cluster setup used:

    module load AFNI/23.3.07-foss-2022b-Python-3.10.8
    source ~/py310_env/bin/activate

-----------------------------------------------------------------------------------------------------------------

5. Combine codon-usage and RDCU output - Codon_usage_extract.sh

Purpose:
Combine the individual .blk and *_RDCU.csv files from all genomes into two files that can be imported into R.

Input:
- The .blk files generated by the Python codon-analysis script
- The *_RDCU.csv files generated by genome_cutot_RDCU.py

Output:
- combined_codon_usage.csv
- combined_codon_pair_usage.csv

Run this script in the directory containing the .blk and *_RDCU.csv files.

The combined codon-usage file contains fields including:
- organism
- codon
- amino acid
- codon positions
- third-position GC indicator
- organism total
- codon count
- RSCU
- GC3

The combined codon-pair file contains fields including:
- organism
- codon pair
- constituent codons
- RDCU
- observed and expected codon-pair counts
- constituent amino acids
- observed and expected amino-acid-pair counts

-----------------------------------------------------------------------------------------------------------------

6. Combine tRNA-gene results - trna_extract_script.sh

Purpose:
Combine the tRNA prediction output files into one table.

Important:
The tRNA gene prediction itself was performed separately by Megha. This script only extracts the relevant information from those output files and combines it.

Input:
- One *_trnas.out file per genome

Output:
- trnas_summary.csv

The output contains:
- organism
- tRNA type
- anticodon
- inference score
- note

Run this script in the directory containing the *_trnas.out files.

-----------------------------------------------------------------------------------------------------------------

7. Download taxonomy - Download_taxonomy.sh

Purpose:
Retrieve taxonomy information for the accessions using the NCBI datasets command-line program and jq.

Input:
- accessions.txt

Output:
- lineages.tsv

The output contains:
- accession
- organism
- taxid
- domain
- phylum
- class
- order
- family
- genus
- species

Requirements:
- NCBI datasets command-line program at the path configured in the script
- jq

The original cluster setup used:

    module load jq

The script processes the accessions in batches of 20 and removes the temporary batch files when finished.

Run from the folder containing accessions.txt.

-----------------------------------------------------------------------------------------------------------------

8. Overall workflow

The main workflow was:

1. Prepare accessions.txt.
2. Download genomes with Download genomes.sh.
3. Unzip the downloaded genome files.
4. Collect the CDS FASTA files into one cds_files folder.
5. Run genome_cutot_RDCU.py over the CDS files.
   (genome_cutot.py can be used instead when RDCU is not needed.)
6. Run Codon_usage_extract.sh to combine the codon/RDCU results.
7. Use the already-generated *_trnas.out files with trna_extract_script.sh to create trnas_summary.csv.
8. Run Download_taxonomy.sh to create lineages.tsv.
9. Import the resulting CSV/TSV files into the R project for the statistical analyses.

The main files passed on to R were:

- combined_codon_usage.csv
- combined_codon_pair_usage.csv
- trnas_summary.csv
- lineages.tsv

-----------------------------------------------------------------------------------------------------------------

9. Notes

- Several scripts contain paths specific to the original cluster account and project directory. These paths need to be changed before reuse on another system.
- The Python codon-analysis scripts expect CDS sequences to be in-frame nucleotide sequences and process them in consecutive groups of three nucleotides.
- The scripts were written for this project and are primarily intended to reproduce the data-preparation workflow used for the analysis.
- The statistical analysis itself was performed separately in R; these scripts produce the input data for that analysis.
