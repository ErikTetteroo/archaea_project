Rchaea
--------------------------------------------------------------------------------------------------------
R analysis project for the archaeal tRNA, codon usage and codon-pair analyses.

The main analysis workflow is contained in workflow.R. Running this script from the R project should run the data preparation, statistical analyses and plotting steps in sequence.
Each script can be run from workflow.R or you can access them manually

--------------------------------------------------------------------------------------------------------
Folder structure
Archive/
Old, exploratory or superseded scripts that are not part of the main workflow.

cluster_scripts/
Python/Bash scripts used on the cluster to obtain and process the genome data. This folder contains its own README with instructions.

Plots/
Output folder for generated plots and figures. This folder should be empty in the GitHub repository; plots are generated when the analysis is run.

Data/ 
Data used and generated by the analysis.
	- Raw_data/ not available on github, the folder with Raw_data should be placed here

	- cleaned_data/ contains generated intermediate datasets.

	- manuscript/ contains generated/intermediate files related to the manuscript comparison.

R/
Reusable R functions used throughout the project. load_project.R loads the required packages and project functions.

Scripts/
Scripts for data preparation, statistical analyses and plotting.

Rchaea.Rproj
RStudio project file.

workflow.R
Main script for running the analysis in sequence.


--------------------------------------------------------------------------------------------------------

Required R packages

The following packages should be installed before running the analysis:

library(tidyverse)
library(dplyr)
library(tidyr)
library(stringr)
library(tibble)
library(ggplot2)
library(patchwork)
library(purrr)
library(ape)
library(phylolm)
library(lme4)

R/load_project.R attempts to load these packages and is called by the analysis scripts.

--------------------------------------------------------------------------------------------------------

Required input files

To rerun the analysis, the following files are expected in:

Data/Raw_data/

archaea_complete_curated_zenodo.csv	<-	Dataset from the archaeal tRNA manuscript.
Assembly_Acc_manuscript.txt		<-	Accessions of genomes included in the manuscript.
combined_codon_pair_usage.csv		<-	Codon-pair usage output generated by the cluster scripts.
combined_codon_usage.csv		<-	Codon usage output generated by the cluster scripts.
filtered_690.tree			<-	Phylogenetic tree obtained from the Megha.
lineages.tsv				<-	Taxonomy output generated by the cluster scripts.
trnas_summary.csv			<-	tRNA prediction output generated by the cluster scripts.

The cluster-generated files can be produced using the scripts in cluster_scripts/; see the README in that folder for details.

Running the analysis

Open Rchaea.Rproj in RStudio go through the workflow.R script

The workflow script documents the sequence of the analysis and the scripts used at each stage. Generated cleaned datasets and plots are written to the corresponding Data/cleaned_data/ and Plots/ folders.
